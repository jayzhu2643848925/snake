# Snake Arena

A neon-style 360° Snake Arena game with AI opponents, power-ups, collectibles, difficulty levels, and real-time survival gameplay.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Controls

- Drag or click the direction wheel for 360° movement.
- Use `WASD` or arrow keys for directional movement.
- Hold `Shift` or the boost button to accelerate.
- Press `Space` or the wheel center button to pause.

## Gameplay

- Collect regular food and golden stars to grow.
- Consume defeated AI snake remains for extra growth.
- Pick up moving magnet power-ups to attract food for 7 seconds.
- Pick up moving shield power-ups for 7 seconds of collision protection.
- AI snakes spawn continuously and receive a temporary shield when they appear.
